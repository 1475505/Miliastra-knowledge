# 一、造物扰动装置组件的功能

造物扰动装置是赋予动态物件，可以对与其发生碰撞的造物施加模拟物理作用力的功能

造物扰动装置组件可支持同时配置多个造物扰动装置，但是同时只能生效一个

# **二、造物扰动装置组件的编辑**

## 1.添加组件

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/f7ebc743-f636-4715-98b6-a6cbc5d4d85d.png)

在实体或元件编辑界面中，打开组件编辑页签

点击下方的“添加通用组件”，选择并点击“造物扰动装置”，成功添加

点击“详细编辑”，展开编辑页

## 3.造物扰动装置的类型

### **(1)弹射器**

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/fd90c325-b497-4987-8572-52e0f319b4a0.png)

该作用力让造物在配置朝向上的速度额外增加对应配置值。

弹射器施加过程中，若检测到某朝向发生碰撞，会把该分量上施加的弹射器清除。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/784feb0e-1832-48a3-baf8-33a926145bc9.png)

**装置规则**

当扰动方向配置为指定方向时，可额外配置方向向量。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/86c92546-a828-488e-b22f-8e905db095ae.png)

当扰动方向配置为关联造物扰动方向时，可配置：

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _造物至实体连线方向_ | 造物与实体中心连线，朝向实体中心 |
| _实体至造物连线方向_ | 造物与实体中心连线，朝向造物 |

其它可配置参数

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _运动速率(m/s)_ | 造物碰撞进入范围时被额外施加可造成该速度的弹射器 |
| _稳定阶段时长(s)_ | 造物持续受到弹射器的时间 |
| _衰减阶段时长(s)_ | 稳定阶段结束后，弹射器速度逐渐减为0的时间 |
| _非浮空状态是否可离地_ | 开启时，造物受弹射器作用期间进入扰动控制状态，弹射器失效或速度减为0时失去 |

### **(2)** 牵引器

该作用力让造物以配置速度在扰动时间内朝向牵引终点拖拽过去。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/0b740348-fd15-42cb-b7f2-5024646c1688.png)

**牵引终点**

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _偏移_ | 牵引终点和编辑实体的位置偏移量 |
| _半径_ | 造物到达牵引终点附近半径距离时算作抵达终点 |

**装置规则**

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _运动速率（m/s）_ | 造物发生碰撞后会被额外施加可造成该速度的牵引器 |
| _稳定阶段时长(s)_ | 造物持续受到牵引器的时间，期间维持速率 |
| _衰减阶段时长(s)_ | 扰动时间结束后，牵引器速度逐渐减为0的时间 |
| _抵达终点时终止_ | 激活时造物到达终点半径距离可提前结束受力 |
| _非浮空状态是否可离地_ | 开启时，造物受牵引器作用期间进入扰动控制状态，牵引器失效或速度减为0时失去 |

备注：牵引器内置持续时间上限30s，防止无法抵达终点而持续运行。

### **(3)力场器**

该作用力让造物在生效范围内持续受力，在不同的范围受到的作用力支持配置不同效果

造物在配置的生效范围不同区域内，将持续被施加相应的作用力，常用于持续的对造物的聚集或推离

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/544b2f7c-daca-4314-b37a-c318a204e239.png)

力场器的施加是以该同心球为核心施加的

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/84860724-2b89-4173-bb17-783895dbb47c.png)

|     |     |
| --- | --- |
| 配置参数 | 说明 |
| _内球半径(m)_ | 力场逻辑生效范围的同心球的内球半径 |
| _外球半径(m)_ | 力场逻辑生效范围的同心球的外球半径 |
| _偏移_ | 力场逻辑生效范围球体的中心，和实体位置的偏移 |

**装置规则**

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhr24urr9kjq/d4254667-20e6-4788-b130-74eeaae99360.png)

当扰动方向配置为_指定方向_时，可额外配置方向向量。

当扰动方向配置为_球心与触发区中心连线方向_时，可配置：

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _远离球心_ | 造物与球心连线，朝向造物（斥力） |
| _朝向球心_ | 造物与球心连线，朝向球心（引力） |

其它可配置参数：

|     |     |
| --- | --- |
| **配置参数** | **说明** |
| _衰减方向_ | 分为由外向内和由内向外 |
| _衰减速率_ | 范围内的力场器的衰减速率 |
| _速率(m/s)_ | 力场器的影响强度 |
| _覆写造物重量_ | 生效时是否统一按指定重量计算，而非造物本身重量 |
| _造物重量_ | 仅在选择覆写造物重量时显示 |
| _非浮空状态是否可离地_ | 开启时，造物受力场器作用期间进入扰动控制状态，力场器失效或速度减为0时失去 |

**力场器范围效果**

造物在内径范围内，受到内球半径的配置力效果

造物在内外半径之间，受到内外径之间的过渡效果

造物在外径之外，受到外球半径之外的配置力效果

# 三、注意事项

当参数配置为开启时，造物在扰动期间可进入扰动控制状态：进入时可受重力及y轴方向的力；进入时会打断AI行为、期间战术和技能无法生效。
