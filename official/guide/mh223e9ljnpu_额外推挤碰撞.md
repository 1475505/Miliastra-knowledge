# 一、额外推挤碰撞组件的功能

额外推挤碰撞组件的配置与额外碰撞组件基本保持一致

但额外推挤碰撞组件只能被部分复杂造物添加

并且额外推挤碰撞区域需要挂载在复杂造物的挂点上

# 二、额外推挤碰撞组件的编辑

## 1.添加组件

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh223e9ljnpu/b99be80a-32f5-4482-984d-0a1c06eae77c.png)

(1)在复杂造物编辑界面中，打开组件编辑页签

(2)点击下方的“添加通用组件”，选择并点击“额外推挤碰撞”，成功添加

选中“额外推挤碰撞组件”时，编辑中的实体会以蓝色显示“额外碰撞”组件当前生效的范围。

(3)点击“详细编辑”，展开编辑页

## 2.额外碰撞的编辑

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh223e9ljnpu/7e52fbce-ea4b-4359-9a05-a8084cb732f4.png)



通过点击![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh223e9ljnpu/61f36983-7c43-43b2-91ea-4fe6235d8b7d.png)，添加“额外推挤碰撞”。



新增的“额外推挤碰撞”，默认配置初始生效。



“序号:X”，X为“额外推挤碰撞序号”，作为节点输入项可以调整额外推挤碰撞的参数

通过“添加额外推挤碰撞”，可增加基础形状

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh223e9ljnpu/18a08276-69b5-456b-853d-cdecf124e6c5.png)

|     |     |
| --- | --- |
| 配置参数 | 说明 |
| _挂接点_ | 该额外推挤碰撞的挂接点 |
| _触发区形状_ | 支持配置长方体、球体、胶囊体三种基础形状<br>![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh223e9ljnpu/24552e4f-9ac9-4995-af5b-40c2569f071b.png) |
| _中心_ | 相对实体或元件中心的偏移 |
| _缩放倍率_ | 支持配置形状在不同轴向上支持定义缩放 |
| _旋转_ | 以中心位置为基准，在不同轴向上支持调整朝向 |
