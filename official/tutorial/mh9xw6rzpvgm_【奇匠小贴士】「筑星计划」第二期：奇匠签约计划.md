# 一、什么是「奇匠签约计划」

作为「筑星计划」成长链路的重要一环，「奇匠签约计划」面向度过新手阶段、渴望更进一步的奇匠，为大家铺好下一段进阶之路，把“被更多人认可”的期待落到实处。

它是千星奇域为优秀奇匠设立的专项创作扶持计划——在奇匠为千星奇域的玩家创作有趣、有创意的内容时，官方将为你提供更丰富的创作收益与资源扶持，让源源不断的创作力在千星奇域持续绽放。

# 二、签约奇匠有机会获得：



### 官方商单，稳定收益

签约奇匠将有机会获得官方派发的合作商单。奇匠承接商单后，按要求制作、交付质量达标的奇域关卡，即可获得相应的制作补贴——让每一份认真交付都有确定的回报。



### 流量激励，优作多得

好作品值得被更多人看见。表现优异的作品，在商单制作补贴之外，还可能额外获得流量激励——让用心打磨作品的奇匠更有持续创作下去的底气。



### 专属权益，官方护航

签约奇匠还能获得：奇匠中心专属标识、专属活动与合作权益优先参与、解锁更多类型的制作收益……

未来更多专属权益，敬请期待~

# 三、如何加入「奇匠签约计划」

奇匠可通过“发送签约意向”进入官方签约意向池，官方将定期结合当期需求，从中邀请部分奇匠进行合作签约。

### Step1：解锁“发送签约意向”功能

奇匠们可以通过持续的新内容创作和旧作品打磨，达成“发送签约意向”功能的解锁条件。小伙伴们度过新手阶段后，就可以把“解锁‘发送签约意向’”作为下一个阶段性目标继续创作啦！

_（解锁条件可能随着版本更迭而改变，具体以功能页面展示为准。__）_

### Step2：表达你的签约意愿

进入签约意向填写页面，填写信息并发送，就成功向官方表达了你的签约意愿，进入签约意向池。意向信息支持定期更新，无论是创作方向有了变化、作品有了明显精进，还是只想更新一下个人信息，都可以重新发送签约意向，刷新你在意向池中的信息。

### Step3：等待官方签约邀请

官方会结合不同阶段的签约需求，定期向部分奇匠主动发出签约邀请，意向池内的奇匠都会优先作为邀请对象来考虑。获得签约邀请的奇匠，将会在奇匠中心、以及填写签约意向时留下的邮箱中收到邀请信息，点击链接即可完成签约。

_小助手的悄悄话：玩法趣味有创意、内容丰富有吸引力、创作活跃有热情、作品品质出众的奇匠，更有可能早日获得签约邀请喔~_
